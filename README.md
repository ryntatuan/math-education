## 🌟 Giới Thiệu Dự Án

**Toán Vui** là ứng dụng giáo dục toàn diện dành cho học sinh tiểu học từ **Lớp 1 đến Lớp 5**, kết hợp hoàn hảo giữa **phương pháp sư phạm trực quan CPA (Cụ thể – Hình ảnh – Trừu tượng)** và **hệ sinh thái Gamification (trò chơi hoá)** giúp trẻ tự giác học tập, rèn luyện tư duy logic, học mà chơi — chơi mà học mà không hề cảm thấy áp lực.

Ứng dụng hoạt động mượt mà trên cả trình duyệt Web và thiết bị di động (Android APK & iOS PWA), hỗ trợ học tập cả khi trực tuyến lẫn khi ngoại tuyến (Offline).

## ✨ Tính Năng Nổi Bật

### 1. 📚 Giáo Trình Toàn Diện Chuẩn GDPT 2018 (488 Bài Học · 65 Chương)

- **Lớp 1 (97 bài):** Nhận biết số 0–100, đếm trực quan với khung 10 chấm (Ten-frame) và vector côn trùng sinh động; phép cộng trừ phạm vi 10 & 100 không nhớ; hình học cơ bản (vuông, tròn, tam giác, chữ nhật, khối lập phương, hộp chữ nhật); xem đồng hồ đúng giờ và đo độ dài xăng-ti-mét.
- **Lớp 2 (100 bài):** Bảng nhân & chia 2, 3, 4, 5; phép cộng trừ có nhớ phạm vi 100 & 1000; đo lường thực tế ($dm, cm, m, km, kg, l$); hình học trực quan (điểm, đoạn thẳng, đường gấp khúc, tứ giác $ABCD$); đọc lịch và xem giờ chính xác đến 5 phút.
- **Lớp 3 (108 bài):** Bảng nhân & chia 6, 7, 8, 9; phép chia có dư; làm quen phân số đơn giản ($1/2, 1/3, 1/4...$); chu vi & diện tích hình chữ nhật, hình vuông; hình tròn tâm $O$, bán kính $r$, đường kính $d$; tiền Việt Nam và bảng số liệu thống kê.
- **Lớp 4 (99 bài):** Số có nhiều chữ số (hàng triệu); phép tính phân số chuyên sâu; góc nhọn, góc tù, góc bẹt; đường thẳng song song và vuông góc; hình bình hành, hình thoi; sơ đồ đoạn thẳng và biểu đồ cột.
- **Lớp 5 (84 bài):** Số thập phân và 4 phép tính; tỉ số phần trăm; diện tích hình tam giác, hình thang, hình tròn; hình hộp chữ nhật, hình lập phương (diện tích xung quanh, thể tích); toán chuyển động đều ($s = v \times t$); biểu đồ hình quạt tròn và xác suất thực nghiệm.

---

### 2. 🐾 Hệ Sinh Thái Thú Cưng Đáng Yêu (Pet Economy)

- Bé nhận nuôi 5 người bạn đồng hành ngộ nghĩnh: *Mèo Cam 🐱, Thỏ Con 🐰, Cún Vàng 🐶, Gấu Trúc 🐼, Khủng Long 🦖*.
- Chăm sóc thú cưng mỗi ngày: Cho ăn bánh pizza, táo đỏ; chơi bóng len, xe đồ chơi để tăng chỉ số No và chỉ số Vui.
- **Tiến hóa & Lên cấp:** Khi thú cưng tích luỹ đủ điểm thân thiết sẽ thăng cấp Vương Miện 👑 và mở khoá các bộ trang phục, ngoại hình đặc biệt.
- Hộp quà may mắn hằng ngày nhân đôi điểm kinh nghiệm (XP Boost Timer).

---

### 3. 🏆 Đấu Trường Thi Đua Tuần & 7 Cấp Bậc Giải Đấu (Leagues)

- Hệ thống bảng xếp hạng tuần tự động chia bảng theo năng lực học tập:
  - 🥉 **Giải Đồng** $\rightarrow$ 🥈 **Giải Bạc** $\rightarrow$ 🥇 **Giải Vàng** $\rightarrow$ 💎 **Giải Kim Cương** $\rightarrow$ 👑 **Giải Cao Thủ**
  - Vòng thi đấu đỉnh cao: ⚔️ **Tứ kết Vô Địch** $\rightarrow$ 🔥 **Bán kết Vô Địch**.
- Tích luỹ XP khi giải toán, làm bài tập và chơi game để nằm trong **Top 10 Thăng Hạng** vào 23:59 Chủ Nhật hằng tuần.
- Lưu trữ Cúp vô địch vĩnh viễn trên hồ sơ của bé.

---

### 4. 🎁 Nhiệm Vụ Hằng Ngày & Modal Nhận Quà Rực Rỡ

- 3 nhiệm vụ rèn luyện thói quen mỗi ngày: *Hoàn thành bài học, chơi mini game và chăm sóc thú cưng*.
- **Rương Thưởng Ngày:** Hoàn thành đủ 3 nhiệm vụ để mở rương nhận **+50 Xu Vàng & +60 XP** với Pop-up hoạt ảnh rương mở phát sáng lung linh kèm pháo hoa và âm thanh chiến thắng.
- **Chuỗi học tập (Streak 🔥):** Duy trì chuỗi ngày học liên tục tính theo giờ địa phương của bé, giúp hình thành tính kỷ luật tự giác.

---

### 5. 🧠 Sổ Tay Lỗi Sai & Ôn Tập Ngắt Quãng (Spaced Repetition)

- Tự động ghi lại những câu hỏi bé trả lời chưa đúng vào sổ tay cá nhân.
- Ứng dụng thuật toán **Lặp lại ngắt quãng (Spaced Repetition)**: Đưa câu sai vào danh sách ôn tập sau 1 ngày $\rightarrow$ 3 ngày $\rightarrow$ 7 ngày cho đến khi bé hoàn toàn thành thạo (Mastered).
- Đồng bộ dữ liệu lỗi sai lên Cloud Supabase để phụ huynh dễ dàng nắm bắt lỗ hổng kiến thức của con.

---

### 6. 🎮 Kho Mini Games Rèn Luyện Phản Xạ Toán Học

- **🏎️ Cuộc Đua Toán Học (Math Race):** Bé tranh tài cùng Thỏ Tốc Độ, Rùa Chăm Chỉ và Mèo Vàng, nhẩm tính thần tốc để tăng tốc về đích.
- **🎯 Bắn Bóng Số Bay (Number Pop):** Tính nhẩm nhanh và chọn bắn đúng quả bóng mang kết quả chính xác trong 45 giây.
- **🃏 Lật Thẻ Trí Nhớ (Memory Match):** Rèn luyện trí nhớ không gian và khả năng ghép đôi phép tính với đáp số.
- **⚖️ Cân Bằng Toán Học (Math Balance):** Đặt các quả cân để giữ thăng bằng cho đòn cân thông minh.
- **🎣 Câu Cá Thông Minh (Math Fishing):** Thả cần câu đúng chú cá mang kết quả đúng của phép tính.
- **🛡️ Vệ Sĩ Toán Học (Math Defender):** Nhẩm tính giải cứu vương quốc khỏi quái vật số học.

---

### 7. 🔊 Giọng Đọc Tự Động (TTS Tiếng Việt) & Âm Thanh Không Độ Trễ

- **Tự động đọc bài học:** Hệ thống Text-to-Speech (TTS) tự động đọc to đề bài bằng giọng nữ tiếng Việt truyền cảm, hỗ trợ tối đa cho học sinh Lớp 1 – 2 chưa đọc thành thạo chữ viết.
- **Âm thanh Native Web Audio API:** Tự động tổng hợp âm thanh đa tần số tức thời không cần tải file MP3 bên ngoài:
  - Âm hợp âm vui tươi khi làm đúng (`playCorrect`).
  - Âm thanh nhẹ nhàng, khuyến khích khi làm sai (`playWrong`).
  - Tiếng leng keng rộn rã khi nhận xu (`playCoin`).
  - Điệp khúc chiến thắng hào hùng (`playFanfare`).

---

### 8. 👨‍👩‍👧 Bảng Theo Dõi Dành Cho Phụ Huynh (Parent Dashboard)

- Vào xem trực tiếp tiện lợi (đã gỡ bỏ mã PIN phức tạp theo phản hồi người dùng).
- **Biểu đồ radar năng lực 5 trục:** *Số học · Phép tính · Hình học · Đo lường · Giải toán có lời văn*.
- Báo cáo chi tiết: Thời lượng học tập, tỷ lệ trả lời đúng, danh sách bài học cần ôn luyện và biểu đồ tiến độ qua từng tuần.

## 🚀 Hướng Dẫn Cài Đặt & Phát Triển

### Yêu cầu hệ thống:
- **Node.js** phiên bản 20.0.0 trở lên.
- **npm** (đi kèm Node.js).
- *(Tuỳ chọn khi build Android)*: Java JDK 21 và Android Studio / Android SDK.

### 1. Clone repository về máy:
```bash
git clone https://github.com/ryntatuan/math-education.git
cd math-education
```

### 2. Cài đặt các gói phụ thuộc:
```bash
# Cài đặt cho client
cd client
npm install
```

### 3. Khởi chạy môi trường phát triển (Dev Server):
```bash
npm run dev
```
Truy cập vào trình duyệt: **`http://localhost:5173`**

### 4. Chạy bộ kiểm thử tự động (Unit Tests):
```bash
# Chạy 188 bộ test tự động
npm test

# Kiểm tra phân tích tĩnh mã nguồn
npm run lint
```

### 5. Đóng gói ứng dụng (Production Build):
```bash
# Build bản Web (output tại client/dist)
npm run build:web

# Tự động tăng version và đóng gói APK Android Release
npm run build
```

## 📱 Đóng Gói Mobile App (Android APK & iOS)

Toán Vui được đóng gói bằng **Capacitor 7.6**, tối ưu hoá 100% trải nghiệm chạm vuốt trên màn hình cảm ứng:
- **Tự động đóng gói APK:** GitHub Actions tự động kiểm thử và biên dịch APK Release mỗi khi có commit mới lên nhánh `main`.
- **Tải trực tiếp:** Người dùng tải bản APK mới nhất tại đường dẫn `/downloads/ToanVui.apk`.
- **Đồng bộ mã nguồn Mobile tại máy:**
  ```bash
  cd client
  npm run mobile:sync        # Đồng bộ web assets vào Android/iOS
  npm run mobile:android     # Mở dự án trong Android Studio
  ```
